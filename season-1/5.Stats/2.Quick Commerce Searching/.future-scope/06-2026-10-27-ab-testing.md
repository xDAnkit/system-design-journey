# 06. A/B testing of ranking

| Field | Value |
|---|---|
| Added | 2026-10-27 |
| Status | Later |
| Effort | Medium |
| Fits in phase | 6 (analytics) |

## What

Split shoppers into buckets, for example keyword only, hybrid, and hybrid + rewrite. The dashboard compares CTR, ADD rate and zero-result rate per bucket.

## Why

It proves with data, not opinion, which search setup is better. Strong material for the video.

## How

- Bucket = hash(sessionId) % N, so a shopper always lands in the same bucket.
- Every search, click and ADD event carries the bucket id.
- Rollups get a bucket field. The dashboard shows each bucket side by side with its sample size and a simple confidence range.
- Buckets and their split come from config (env or the Settings page).

## Watch out

- Run long enough. With few searches the difference is noise.
