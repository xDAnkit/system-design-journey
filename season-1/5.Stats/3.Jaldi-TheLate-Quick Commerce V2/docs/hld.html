Jaldi V2 - High Level Design

Quick Commerce Search (Blinkit-style). Source: this repo's code, file:line noted where it matters.

1. Components (real, from code)

Fastify API
Node 24, port 5004
MongoDB
db jaldi, source of truth
Typesense
:8108, hybrid search
Kafka
:9094, 5 topics, prefix jaldi.
Redis
DB 1, cache + live counters
Ollama
gemma3:4b tags, bge-m3 vectors (default, free, local)
Cloud AI (optional)
Anthropic / Gemini / OpenAI, only if API key set
UI
Plain HTML + Tailwind CDN, no build step

3. Flow: Admin Adds a Product

sequenceDiagram
  participant A as Admin
  participant API as Fastify
  participant K as Kafka
  participant W1 as ingest worker
  participant M as MongoDB
  participant W2 as enrich worker
  participant AI as Ollama
  participant W3 as index worker
  participant TS as Typesense

  A->>API: POST /products
  API-->>A: 202 Accepted
  API->>K: topic products.ingest
  K->>W1: consume
  W1->>M: insert (status: pending)
  W1->>K: topic products.enrich
  K->>W2: consume
  W2->>AI: get tags + vector
  Note over W2: admin tags present -> LLM tagging skipped
  W2->>M: update tags + vector
  alt fails 3 times
    W2->>K: products.enrich.dlq
  else ok
    W2->>K: topic products.index
    K->>W3: consume
    W3->>TS: upsert into alias "products"
  end

4. Flow: Shopper Searches

sequenceDiagram
  participant S as Shopper
  participant API as Fastify
  participant R as Redis
  participant TS as Typesense
  participant K as Kafka
  participant W4 as analytics worker
  participant M as MongoDB

  S->>API: GET /search?q=...
  API->>API: parse query (brand, size, price, intent)
  API->>R: check cached rewrite / vector
  API->>TS: hybrid search (keyword + vector)
  TS-->>API: ranked results
  API-->>S: response
  API->>K: topic search.events
  K->>W4: consume
  W4->>M: raw event (90 days) + daily counters
  W4->>R: live ticker, unique visitors
  Note over W4: vector-only hit becomes an AI-suggested tag candidate (needs admin approval)

5. Facts Worth Knowing

  • Kafka delivery is at-least-once, a crash can double-count analytics (fine for dashboards, per repo notes).
  • products.enrich.dlq catches a product after 3 failed enrich attempts.
  • Admin routes need header x-admin-key. No JWT, despite .env.example having leftover JWT vars (unused in code).
  • Shares Kafka + Typesense containers with V1 (Quick Commerce Searching), own data by prefix (jaldi., jaldi_) and own Mongo db / Redis DB.
  • Only REST + Kafka found in code. No WebSocket, gRPC, or GraphQL.
  • No formal test framework. Only plain node:assert self-checks (pnpm check), no DB/Kafka/HTTP involved in those checks.
